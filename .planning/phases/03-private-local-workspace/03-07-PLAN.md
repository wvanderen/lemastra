## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored inputs → prefilled form | Stored data crosses into editable state — parsed with zod, unknown ids route home |
| revise flow → recalculation API | The only Phase-3 path that intentionally re-calls the API — the unchanged Phase-2 confirm chain, disclosure already acknowledged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-22 | Tampering | silent basis change (prior analysis re-pointed at new inputs) | mitigate | append-only revisions + (chart, input_revision) dedupe (03-03-proven); read-only earlier views; visible "stays in History" trust language |
| T-03-23 | Tampering | revise param malformed (chartId/inputs spoofed via deep link) | mitigate | local zod parse of the revise param; malformed → fall back to the fresh-flow form (never a crash, never unvalidated prefill) |
| T-03-24 | Repudiation | user cannot tell what a revision changed | mitigate | fixed-vocabulary human phrases derived from pure input diffs — never raw diffs, never invented interpretations |
</threat_model>
