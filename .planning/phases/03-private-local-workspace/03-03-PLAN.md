## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored rows → rendered data | Every read crosses from frozen JSON to live render — parse-then-trust gate |
| user input (labels) → SQL | Parameterized through drizzle only |
| repository module → network | PRIV-01 forbids any egress from the persistence layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Tampering | SQL injection via labels/ids | mitigate | drizzle query builder / prepared statements only — never string-concatenated SQL (repo law, review-enforced) |
| T-03-08 | Tampering | silent basis change (revision mutation) | mitigate | append-only rows; rename touches chart metadata only; byte-equality immutability tests in this plan's matrix |
| T-03-09 | Tampering | schema-confusion reopen (stored data rendered unvalidated) | mitigate | zod parse at every read; failures surface as typed WorkspaceError OPEN_FAILED, never partial render (Pitfall 1); frozen-fixture regression catches schema drift |
| T-03-10 | Information Disclosure | orphaned personal data after deletion | mitigate | explicit transactional cascade (revisions then chart) — FK pragma never trusted (Pitfall 2); delete-all wipes personal tables only (Pitfall 9) |
| T-03-11 | Information Disclosure | persistence layer egress | mitigate | no-network source-scan test (PRIV-01) — the stored envelope IS the evidence |
