| user label → filesystem | Export filenames derive from user labels — slug sanitization is the gate |
| app sandbox → other apps | The share sheet is the only intentional egress for chart data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-18 | Tampering/Elevation | path traversal / unsafe filenames via label | mitigate | slug derivation (alphanumeric+dash, capped, constant fallback) BEFORE File construction — unit-tested with emoji/space/slash labels |
| T-03-19 | Information Disclosure | accidental deletion (or silent data loss) | mitigate | modal confirmation naming scope + permanence (D-14); cancel default; explicit transactional cascade proven in 03-03 |
| T-03-20 | Information Disclosure | export data remanence | accept | Export files are user-initiated share artifacts in the sandbox cache dir, documented in /privacy copy; transient by cache semantics |
| T-03-21 | DoS | Android share rejection (Pitfall 7) | mitigate | capability gate + always sharing a cache-dir file uri from the OO File API — the exact path the native module accepts |
</threat_model>
