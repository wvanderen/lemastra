## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API process → calculator subprocess | JSON payload crosses into an AGPL tool executed as a child process |
| environment → API process | env vars (incl. GOOGLE_API_KEY) inherited by children unless stripped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | calculator.py subprocess exec | mitigate | never shell=True; argv fully controlled (--input tempfile + validate in JSON); payload reaches process as file content, not shell text |
| T-02-02 | Elevation | calculator subprocess env | mitigate | strip GOOGLE_API_KEY (and any *KEY*/*SECRET* vars) from the child environment |
| T-02-03 | DoS | calculator.py | mitigate | per-request subprocess + asyncio.wait_for timeout (10 s default, ~250× headroom over verified 40 ms runtime) + kill() |
| T-02-04 | Information Disclosure | server logs | mitigate | subprocess stdout/stderr discarded after error-code extraction; no birth-payload logging (retention §1 compute-and-discard) |
| T-02-05 | Tampering | vendored skill | mitigate | submodule gitlink pins 660d992; provenance reads git rev-parse at startup so a tampered tree is visible in every health/chart response |
</threat_model>
