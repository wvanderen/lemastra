## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → places endpoints | Untrusted query/coordinate input |
| API → Google Maps APIs | Outbound call carrying the server-side API key |
| Google response → API models | Third-party data re-serialized to clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-geo | Information Disclosure | GOOGLE_API_KEY | mitigate | key read only from settings/env, lives only in gitignored api/.env, never in responses/logs/EXPO_PUBLIC_*; absent key → honest provider-unavailable error; gitleaks CI (Phase 1) already scans api/ files |
| T-02-14 | Spoofing/SSRF-adjacent | places/search proxy | mitigate | query forwarded to the fixed Google endpoint only; no arbitrary-URL parameters accepted; min-length validation; response fields parsed from an allowlist |
| T-02-15 | Tampering | timezone identity | mitigate | Google supplies identity only; offsets computed from pinned local tzdata; drift flag surfaces disagreement instead of hiding it |
| T-02-16 | DoS | outbound geocoder calls | mitigate | client debounce (≥300 ms/≥3 chars, enforced in 02-06) + provider status mapping; no caching layer needed for local dev scale |
| T-02-17 | Information Disclosure | resolve-time logs | mitigate | no payload logging; lookup_timestamp is the only per-request metadata retained in responses (ephemeral, retention §1) |
</threat_model>
